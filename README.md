- **🧭 導覽主線（v16）**：島上 8 個有號碼的地標＝8 個互助基金。點地標或按「下一站 →」逐站看，每站都有：
  - 一句話＋3 個大數字（互助費、給付、年齡）
  - 計畫一次看（社員團體 A～F、團體意外計畫一～四、防癌計畫一～三、重大疾病依年齡、幹部 A1～A3）

  - 🎭 狀況劇（LP、LS 直接改寫協會簡章的計算例題）
  - 🔗 可以搭配：點了直接飛到另一站
  - 📄 簡章原文與完整條款
- **「我是誰」身分路線**：👵 長輩 65 歲以上、🧑 上班族青壯、👶 爸媽幫小孩、🎖️ 理監事幹部、✨ 全部逛——自動排好該看的站，島上同步亮出路線。

- **🎮 挑戰區**：原本 5 個小遊戲（核保快刷、互助配對診所、理賠神算偵探社、85 歲人生摩天輪、25 號送件大亂鬥），保留 🌱 輕鬆安心版與 🔥 幹部魔王版、集章護照與戰績卡。
- **沉浸式影音**：Google Flow Music 日夜配樂、媠聲台語＋國語語音、Veo 開場短片、黏土微縮角色；跳出 LINE、切換 App、鎖螢幕時自動停音。

## 🚀 本機開發與部署

### 本機預覽
雙擊資料夾內的 `start_game.bat`，或在專案根目錄執行：
```bash
python -m http.server 8765 --bind 127.0.0.1
```
接著開啟 `http://127.0.0.1:8765/`。

### 核對導覽內容（部署前必跑，需本機 7 份協會簡章 PDF）
```bash
python tools/check_tour_facts.py
```

### 部署至 Cloudflare Workers Static Assets
```bash
wrangler deploy --dry-run
wrangler deploy
```

## 📁 專案結構

- `index.html`：主頁面與 3D 舞台／行動抽屜介面
- `css/styles.css`：行動優先、長輩友善大字排版（檔尾為 v16 導覽樣式）
- `js/data/`：`tour_content.js`（8 站導覽內容、身分路線）、`funds_data.js`（8 大基金條款整理）、`game_content.js`（挑戰區題庫）
- `js/tour/tour.js`：導覽畫面、上一站／下一站、查基金、路線卡
- `js/core/`：素材清單、音效與配樂、本機進度、速查圖鑑、戰績卡與路線卡產生器
- `js/games/`：挑戰區 5 個小遊戲
- `js/scene/island3d.js`：Three.js 19 格 3D 微縮島（站號名牌、身分路線、協作線、鏡頭偏移）
- `assets/`：角色立繪、短片、國台語語音與配樂
- `tools/`：語音製作、導覽內容核對等輔助腳本（不部署至公開網站）
- `wrangler.jsonc` / `.assetsignore` / `_headers`：Cloudflare Workers Static Assets 部署設定
