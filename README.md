## 🚀 本機開發與部署

### 本機試玩
雙擊資料夾內的 `start_game.bat`，或在專案根目錄執行：
```bash
python -m http.server 8765 --bind 127.0.0.1
```
接著開啟 `http://127.0.0.1:8765/` 即可。

### 部署至 Cloudflare Workers Static Assets
```bash
wrangler deploy --dry-run
wrangler deploy
```

## 📁 專案結構

- `index.html`：主頁面與 3D 舞台／行動抽屜介面
- `css/styles.css`：行動優先、長輩友善大字排版與毛玻璃 HUD 樣式
- `js/data/`：`funds_data.js`（8 大基金權威資料）、`game_content.js`（5 攤雙難度題庫）
- `js/core/`：素材清單、音效與日夜配樂引擎、本機進度、速查圖鑑、LINE 戰績卡產生器
- `js/games/`：五大互動小遊戲模組
- `js/scene/island3d.js`：Three.js 19 格 3D 微縮島嶼引擎
- `assets/`：角色立繪、Veo 開場／慶祝短片、國台語語音與日夜原創配樂
- `tools/`：語音、台語與 3D 模型輔助製作腳本（不部署至公開網站）
- `wrangler.jsonc` / `.assetsignore` / `_headers`：Cloudflare Workers Static Assets 部署設定
